# Programming Examples Repository

This repository contains the programming examples used during our class discussions.

The files uploaded here are intended to serve as supplementary learning materials and references to help you review and better understand the concepts, syntax, and programming techniques discussed in class.

You may access and review these examples anytime, especially when working on related activities, exercises, and assessments.

## Important Reminder

Use the examples in this repository as a guide for your learning. Make sure that you understand how each program works rather than simply copying the code.

You are encouraged to run, study, and modify the examples to explore how changes in the code affect the program's output.
